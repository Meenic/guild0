# Guild0 Bot

Discord bot workspace for Guild0. This package is still a placeholder while the bot is being planned.

## Status

Not implemented yet.

## Planned Stack

- **Runtime**: Node.js
- **Language**: TypeScript
- **Package Manager**: pnpm
- **Monorepo Tooling**: Turborepo

## Development

Once the bot has its own scripts, it will be runnable from the monorepo root with:

```bash
pnpm --filter bot dev
```
